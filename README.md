# Журнал работы

Личная страница с тем, что сделано за день. Подходит для любого проекта и для дел вне репозитория: запись — это заголовок, при необходимости подробность, и имя проекта или ситуации.

Страница открывается из Finder как `~/Documents/Рабочий отчет.html`. Календарь сверху по центру, под ним один выбранный день. Стрелки листают дни. Текст пункта можно править на странице: Enter сохраняет и убирает поле, Shift+Enter начинает новый абзац. Справа внизу «Сформировать отчет» скачивает Excel за выбранные даты. Колонки файла: «Дата», «Результат», «Подробнее».

Как формулировать заголовок и подробность — в [WRITING.md](WRITING.md).

## Что не коммитить

Сами записи в этот репозиторий не входят.

- `~/.cursor/work-log/journal.json` — данные
- `~/Documents/Рабочий отчет.html` — собранная страница

Их не копируют в другие проекты и не прикладывают к переписке.

## Запись из терминала

```bash
python3 scripts/append_entry.py \
  --project "имя проекта или ситуации" \
  --text "Кратко, что сделано" \
  --detail "Ситуация, если без неё действие непонятно"
```

Заменить уже записанную строку, а не добавить вторую:

```bash
python3 scripts/append_entry.py \
  --project "имя проекта или ситуации" \
  --update "старый заголовок целиком" \
  --text "новый заголовок" \
  --detail "новая подробность, если она нужна"
```

Посмотреть день:

```bash
python3 scripts/append_entry.py --show --date YYYY-MM-DD
```

Собрать сырьё за день (коммиты и незакоммиченное в `~/PycharmProjects`, без секретов). Это не текст отчёта:

```bash
python3 scripts/collect_day.py --date YYYY-MM-DD
```

## Этот Мак

Правки со страницы принимает небольшая программа на `127.0.0.1:47655`. Она стартует при входе в систему.

```bash
./install.sh
```

Остановить:

```bash
launchctl bootout gui/$(id -u)/local.work-journal
```

Включить снова:

```bash
launchctl bootstrap gui/$(id -u) "$HOME/Library/LaunchAgents/local.work-journal.plist"
```

Кнопка «Открыть Терминал» на странице делает то же включение, когда программа остановлена.

## Если меняешь страницу

Не убирай сохранение правки, кнопку «Остановить», команды и «Сформировать отчет». Календарь остаётся по центру сверху, под ним один день. Быстрый период отчёта заканчивается сегодняшним днём. В файле ровно три колонки.
